# Quant and Apti Tracker

An elite daily training system for quantitative aptitude, logical reasoning, and CS logic, designed specifically for software engineering placement preparation.

## Features
- **30-Day Guided Roadmap**: Structured curriculum covering high-yield topics.
- **Focus Mode Sprints**: Distraction-free exam engine with timer and instant feedback loops.
- **Cheat Sheets**: High-yield formulas, tricks, and patterns before every sprint.
- **Interview Eve Vault**: Save and retry flagged, slow, and incorrectly answered questions.
- **Analytics Dashboard**: Track your accuracy by topic, daily performance trends, and speed metrics.
- **ADHD-Friendly Design**: Minimalist, dark mode, keyboard-first navigation.

## Tech Stack
- React
- TypeScript
- Vite
- Zustand (State Management)
- Tailwind CSS v4
- Framer Motion / Motion
- Recharts

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the development server
